Return of Investment Predictor
WHAT IT IS:
BINHI uses Multinomial Naive Bayes algorithm to generate an AI classifer capable of predicting the likelihood of positive or negative return of investment based on a crop harvest of a specific month. Note that this provide prediction by identifying patterns and trends on historical ROI data.
DATASET REQUIREMENT:
Dataset that is used consists of past and historical data of crop harvests that has information on the ROI of crops per month. ROI may be interpreted as income, production, crop quality, crop price etc.
HOW IT WORKS

The dataset are then numerically converted, vectorized, randomized and split.
- 80% of the dataset are used for training the AI by feeding it to the machine learning model
- 20% of the dataset are used to test the trained machine learning model.
This will produce the scores for the Accuracy, Precision, Recall, F1-Score, Confusion Matrix.

The AI predicts by identifying and recognizing pattern given to it by the dataset. The algorithm also incorporates the Baye's theorem hence the name. The machine learning algorithm are trained the page is loaded. A crop and a month user input is required for user application.

Raw Dataset View - Dataset improvement is advisable. This dataset is not fixed.
